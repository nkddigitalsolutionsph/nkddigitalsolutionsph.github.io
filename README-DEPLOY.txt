NKD DIGITAL SOLUTIONS — MODERN GITHUB PAGES PACKAGE

This is a complete static-site package based on the latest NKD redesign files available in the project materials, with a modern homepage layer added. It includes homepage, founder/portfolio page, tools, learn, blog, privacy, logo, shared styles/scripts, sitemap, robots.txt and supporting templates.

DESIGN
- Main homepage: premium ivory, cobalt blue, lavender and soft coral.
- Main homepage includes an accessible light/dark theme switch, responsive navigation, product-style iPhone dashboard mockup, CTA micro-interactions and a cascading tools/platform slider.
- Founder/portfolio page keeps the existing palette and shared site styling; the new color system is scoped to the homepage only.
- Brand slider identifies platforms/tools and workflows rather than presenting them as client endorsements.
- The phone dashboard is an illustrative UI mockup, not live analytics or a real product dashboard.

DEPLOY
1. Download and unzip this package.
2. Back up the current GitHub repository first.
3. Review the changed index.html, modern-home.css and modern-home.js.
4. Upload the CONTENTS of the folder to the ROOT of https://github.com/nkddigitalsolutionsph/nkddigitalsolutionsph.github.io, replacing existing files only after the backup.
5. Commit to main and wait for GitHub Pages Actions to finish.
6. Test https://nkddigitalsolutions.com/ and /founder/ on mobile and desktop.

NOTES
- Keep your existing custom-domain CNAME file if one is present in the live repository; it may not have been included in the provided ZIP. If your repository currently contains a CNAME file, retain it during upload.
- GitHub Pages deployment success does not by itself prove all interactions and breakpoints are flawless. Test real pages and forms after deployment.
- This package does not push or commit to GitHub on your behalf.
